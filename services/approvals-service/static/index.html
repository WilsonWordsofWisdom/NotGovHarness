Approvals

Review pending actions gated by a real Temporal workflow — approve, reject, or edit.

Needs a bearer token scoped for approvals:decide to act on a request, or any valid token to just browse: curl -X POST http://localhost:8090/oauth/token \ -d grant_type=client_credentials -d client_id=reviewer \ -d client_secret=<reviewer-secret> -d scope=approvals:decide then paste the access_token below.
