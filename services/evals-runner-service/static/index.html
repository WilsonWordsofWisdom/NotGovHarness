Evals Runner

Run a published Eval Registry suite through real DeepEval + Ragas autoraters.

Needs a bearer token scoped for evals:run to submit a run, or any valid token to just browse: curl -X POST http://localhost:8090/oauth/token \ -d grant_type=client_credentials -d client_id=example-service \ -d client_secret=<example-service-secret> -d scope=evals:run then paste the access_token below.

The system-under-test and the judge/autorater are independently configurable — it's fine for them to be the same model, but scoring your own model's output with itself is a known self-preference-bias risk worth being able to separate out.
