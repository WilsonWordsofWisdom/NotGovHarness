Agent Registry

Browse published, signed Agent Cards and verify their signatures. Normally agents are published automatically by Agent Builder.

Normally agents are published automatically by Agent Builder -- use this only to publish a hand-authored, already-signed card. This form does not sign anything itself: identity-service has no CORS configured, so a direct browser call to its /cards/sign from this page would be blocked by every real browser. Get a signature first: curl -X POST http://localhost:8090/cards/sign \ -H "Authorization: Bearer <a token scoped for agentcard:sign>" \ -H "Content-Type: application/json" \ -d '{"name": "my-agent", "version": "0.1.0", "url": "...", "capabilities": {}}' then paste the response's three fields below, alongside a bearer token scoped for registry:publish (the same token can hold both scopes).
