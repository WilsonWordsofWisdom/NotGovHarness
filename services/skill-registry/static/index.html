Skill Registry

Browse published SKILL.md bundles, or publish one of your own.

This form needs a bearer token already scoped for skill_registry:publish — never paste a client secret into a web page. Get one from identity-service first: curl -X POST http://localhost:8090/oauth/token \ -d grant_type=client_credentials -d client_id=<your-client> \ -d client_secret=<your-secret> -d scope=skill_registry:publish then paste the access_token below.
